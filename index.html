Prioritas Utama — Backend

1. Sistem Monitoring Data

Sistem backend berbasis Python dan PostgreSQL yang dirancang untuk menerima, menyimpan, dan menyediakan data secara terpusat melalui antarmuka API.

Problem

Kebutuhan akan pipeline pencatatan data yang andal untuk mengelola data masuk agar tersimpan secara terstruktur dan dapat diakses kembali oleh aplikasi atau pengguna.

Solution

Membangun arsitektur backend menggunakan Python dan basis data relasional PostgreSQL untuk menangani penerimaan data, validasi, penyimpanan, dan penyediaan endpoint API.

Fitur Utama
  • Penerimaan request dan input data terpusat
  • Penyimpanan data relasional terstruktur pada PostgreSQL
  • Penyediaan data melalui API endpoint untuk kebutuhan monitoring
Teknologi & Peran

Teknologi: Python, PostgreSQL, Git

Peran Saya: Backend Developer (Merancang skema database, membangun logika API, dan menguji aliran data)

Proses Pengembangan

Menganalisis kebutuhan data model, merancang tabel relasional pada PostgreSQL, mengimplementasikan logika backend dengan Python, serta menyediakan endpoint API untuk mempermudah akses data.

Hasil

Sistem backend fungsional yang mampu memproses penyimpanan data dan menyediakan data monitoring secara konsisten melalui API.

IoT & Data Analysis

2. Tempat Sampah Pintar Berbasis IoT

Sistem tempat sampah otomatis interaktif berbasis ESP32 yang terintegrasi dengan pemrosesan Python untuk menganalisis intensitas penumpukan sampah.

Problem

Tempat sampah konvensional memerlukan kontak fisik langsung dan rawan meluap jika tidak dipantau secara berkala.

Solution

Mengintegrasikan mikrokontroler ESP32 dengan sensor untuk mekanisme buka-tutup otomatis higienis, penguncian saat penuh, serta analisis data intensitas sampah menggunakan Python.

Fitur Utama
  • Terbuka secara otomatis saat mendeteksi interaksi manusia
  • Sistem pencegahan: otomatis terkunci/tidak dapat terbuka ketika kondisi penuh
  • Analisis data intensitas sampah menggunakan skrip Python
Teknologi & Peran

Teknologi: ESP32, C/C++, Python, Git

Peran Saya: IoT & Software Developer (Memprogram logika ESP32 dan skrip analitik Python)

Proses Pengembangan

Memprogram ESP32 menggunakan C/C++ untuk kendali aktuator/sensor, mengimplementasikan logika validasi kondisi kapasitas sampah, serta mengolah data intensitas keterisian menggunakan Python.

Hasil

Prototipe perangkat pintar yang bekerja secara otomatis dan memberikan data pemantauan intensitas sampah yang siap diintegrasikan lebih lanjut.

Hardware Engineering

3. Voltmeter ADC 1–9 Volt

Alat ukur tegangan digital mandiri berbasis ADC0804 dan dekoder 74LS47 dengan kemasan siap pakai.

Problem: Kebutuhan visualisasi tegangan analog rentang 1-9V ke bentuk display digital diskrit.

Solusi: Mendesain pembagi tegangan (voltage divider) yang tepat agar sinyal dapat dikonversi akurat oleh IC ADC0804 dan ditampilkan via dekoder 74LS47 ke display.

Teknologi: Rangkaian Pembagi Tegangan, ADC0804, 74LS47, Hardware Packaging

Peran: Hardware Engineer (Perancangan skematik, kalibrasi tegangan, perakitan, dan pembuatan packaging)

Hasil: Modul voltmeter digital portabel dengan packaging rapi dan siap pakai.

Hardware Engineering

4. Power Supply Unit Multi-Output

Catu daya teregulasi multi-tegangan yang menyediakan output stabil 5V, 9V, dan 12V untuk kebutuhan laboratorium dan mikrokontroler.

Problem: Perlunya sumber tegangan yang stabil dengan beragam tingkatan voltase dalam satu perangkat pengujian terpadu.

Solusi: Merancang sistem regulasi daya multi-jalur untuk menghasilkan 5V, 9V, dan 12V DC secara stabil di dalam boks packaging yang aman.

Teknologi: Elektronika Analog/Regulator, Hardware Packaging Siap Pakai

Peran: Hardware Engineer (Desain sirkuit daya, perakitan kabel, pengujian beban tegangan, dan perakitan casing)

Hasil: Unit power supply fungsional dan siap pakai untuk menyuplai berbagai sirkuit elektronika dan modul mikrokontroler.
